# Task Intent

## Requested outcome

Make the MTTS submod use English as its source/UI language and store the
Chinese localization under `game/Submods/MAICA_MttsSubmod/tl`.

## Scope

- Convert user-visible MTTS screens, status text, item text, and dialogue
  source strings to English.
- Rebuild translation blocks as `translate chinese` blocks.
- Regenerate dialogue translation identifiers after source text changes.
- Make built-in provider descriptions match the source/UI language and the
  fields consumed by the provider screen.

## Non-goals

- Do not change language selection semantics, TTS target-language routing,
  migration rules, cache rules, logging, comments, or internal test fixtures.
- Do not modify the external MAS checkout or its committed translation tree.

## Acceptance criteria

- English is the default source/UI text when no language is selected.
- MTTS Chinese translations use `translate chinese` and retain Chinese output.
- Dialogue translation labels match the English source text generated by
  Ren'Py.
- Newly covered shared template strings have Chinese translations.
- Existing repository tests pass; Ren'Py-specific checks are reported with
  their environment limitations if unavailable.
